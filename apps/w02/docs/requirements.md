# 用户完整原始需求
# 项目任务：开发眼球视觉原理 3D 交互式可视化网页

你需要从零开始开发一个可在本地运行的 **眼球视觉原理 3D 可视化网页项目**。

项目主要用于通过交互式 3D 眼球模型介绍人眼如何形成视觉，包括光线进入眼球、角膜与晶状体折射、瞳孔调节、晶状体聚焦、视网膜成像以及视觉信息传递等过程。

系统需要同时支持眼球结构查看、结构标注、点击交互，以及完整眼球与半剖视眼球之间的切换。

---

# 1. 项目目标

开发一个本地部署的 Web 端 **眼球视觉原理交互式 3D 教学系统**。

项目的重点不是医学诊断或临床解剖展示，而是：

- 展示眼球中与视觉形成相关的主要结构
- 解释光线如何进入眼球
- 解释角膜与晶状体如何改变光线传播方向
- 展示光线最终如何聚焦到视网膜
- 展示视网膜上的倒立成像
- 解释瞳孔对于进入光量的调节作用
- 解释晶状体调节与远近物体聚焦的关系
- 解释视觉信息如何经视神经传递
- 通过动画、标注和交互帮助用户理解视觉形成原理

界面和 3D 交互形式可以参考：

# 10. 视觉原理核心流程

系统需要围绕以下核心过程设计：

## Step 1：光线进入眼睛

展示来自外界物体的光线向眼球传播。

可以在眼球前方设置：

- 一个简单物体
- 箭头
- 字母
- 图标

用于代表被观察对象。

从该对象发出若干代表性光线。

---

## Step 2：角膜折射

展示：

```text
空气 → 角膜
```

过程中光线发生折射。

需要通过动画让用户观察：

- 入射光线
- 折射后的光线
- 光线传播方向发生变化

角膜是视觉聚焦系统的重要组成部分。

---

## Step 3：瞳孔控制进光量

展示光线通过：

```text
虹膜 → 瞳孔
```

可以通过简单动画表现：

- 明亮环境：瞳孔缩小
- 较暗环境：瞳孔扩大

页面重点解释：

**瞳孔主要控制进入眼睛的光线数量。**

---

# 11. 晶状体聚焦

晶状体是页面核心视觉机制之一。

需要展示光线通过晶状体后进一步发生折射。

至少支持：

```text
远距离观察
近距离观察
```

两种状态。

---

## 11.1 远距离

远处物体：

- 入射光线接近平行
- 晶状体相对较扁
- 将光线聚焦至视网膜

---

## 11.2 近距离

近处物体：

- 入射光线发散程度更高
- 晶状体需要变得更加凸
- 增强折射能力
- 使图像仍能聚焦在视网膜

可以提供：

```text
[观察远处] [观察近处]
```

切换。

模型允许的话，可以通过：

- Morph Target
- Scale
- Shader
- 切换模型

模拟晶状体形态变化。

如果模型暂时不支持形变，可以先通过动画和示意方式实现。

---

```text

```

- Three.js Line
- TubeGeometry

- 发光材质

实现。

需要支持：

- 显示 / 隐藏光线
- 光线动画
- 不同视觉过程使用不同路径
- 与当前教学步骤同步

光线至少经过：

```text
外界物体
→ 角膜
→ 瞳孔
→ 晶状体
→ 玻璃体
→ 视网膜
```

第一版不要求做精确物理级光线追踪。

重点是：

**保证视觉逻辑正确、易理解、表现清晰。**

# 14. 视觉信息传递

可以进一步通过动画展示：

```text
视网膜
→ 视觉感受信号
→ 视神经
```

可以采用：

- 发光粒子
- 流动线条
- 脉冲动画

表现视觉信号沿视神经传播。

第一版不要求展示完整大脑视觉皮层。

页面只需要说明：

**视网膜将光信号转换为神经信号，再通过视神经继续传递。**

# 15. 教学步骤模式

建议建立视觉原理步骤：

```text
1. 光线进入眼睛
2. 角膜折射
3. 瞳孔控制进光量
4. 晶状体聚焦
5. 视网膜成像
6. 视觉信号传递
```

用户可以点击任一步骤。

点击后：

1. 调整 3D Viewer 到适合的视角
2. 高亮相关结构
3. 显示相关光线
4. 播放对应动画
5. 更新右侧说明

建立统一数据结构，例如：

```ts
interface VisionPrincipleStep {
  id: string
  title: string
  description: string
  relatedStructures: string[]
  cameraPreset?: string
  animationType?: string
}
```

用户点击例如：

# 17. 结构信息内容

结构说明应重点解释：

**该结构与视觉形成的关系。**

而不仅仅是介绍解剖位置。

例如：

```text
晶状体
Lens

作用：
晶状体能够通过改变形状调整折射能力，使不同距离物体发出的光线都能够尽可能聚焦到视网膜上。

视觉原理：
观察近处物体时，晶状体变得更加凸；观察远处物体时，晶状体相对变平。
```

# 42. 教学与科学准确性原则

该项目是视觉原理科普与教学系统。

因此：

- 不要为了视觉效果明显违背基础光学原理
- 不需要第一版实现严格物理级 Ray Tracing
- 光线可以使用示意模型
- 光线路径必须符合基本视觉形成逻辑
- 科普文字应简洁、准确
- 避免过度医学专业化
- 避免将系统设计成疾病诊断软件
- 优先保证用户能够理解“为什么能看见”

所有复杂原理优先使用：

```text
3D 动画
+
短文本
+
结构高亮
+
光线示意
```

而不是长篇文字。

# EyeVisPro 开发约定

开始任何开发任务前，先读取 `docs/requirements.md`、`docs/project_memory.md` 和 `docs/architecture.md`。

- 需求变更先更新需求文档，明显架构变化先更新架构文档，再修改代码；重要阶段完成后同步长期记忆。
- 所有面向用户的文字使用中文。数据中的英文名称可供资产映射使用，不直接展示英文界面。
- 模型、光线路径、动画、结构数据和 UI 保持分离；Mesh 名称只在统一映射中处理。
- 第一阶段模型是本地程序几何教学示意；不要引入核心运行必须依赖的远程资产或 SaaS。
- 瞳孔是开口，光线路径不能穿过实体虹膜；上方物点对应下方视网膜像点。
- 使用 useFrame / ref 更新三维动画，React 进度节流同步，避免逐帧状态更新。
- 按变更范围运行 `npm test` 和 `npm run build`；3D / UI 变更应在本地浏览器验证并检查 Console。
- 正式资产统一放在 `public/models/eye/`，接入前记录来源、许可、命名、坐标和尺寸。

# W05 · 运动知觉与时间采样

本周是可继续增加案例的独立应用，首个案例为 **水滴倒流**，入口为 `w05/#water-strobe`。源码和依赖均保存在总工程内。

## 运行

在 `VisualPrinciples-Practice` 根目录运行 `npm run dev`，从课程首页进入 W05。已有根工程及旧周依赖时，只需在本目录首次执行 `npm install --no-audit --no-fund` 安装新周依赖。

只开发本周时，在本目录运行：

```powershell
npm run dev -- --port 5215 --base /w05/
```

随后打开 `http://127.0.0.1:5215/w05/#water-strobe`。独立运行只提供 W05，页面“课程首页”链接需通过总工程服务使用。

本周的最小检查可独立执行 `npm run typecheck`、`npm test`、`npm run build`。`typecheck` 在这个原生 JavaScript 应用中执行语法检查；没有 TypeScript 编译步骤。根工程仍按注册表完成统一构建与发布。

## 案例 01 · 水滴倒流

参考视频：[《水滴为什么会倒流？这是频闪光源导致的》· 李论科学](https://www.bilibili.com/video/BV19W4y1E7qS)。

水滴周期性释放，每一滴都在重力作用下下落。频闪光源只让观察者看到离散时刻的水滴图样；相邻采样中看似同一颗的水滴，可能实际来自不同的水滴。

在光源频率 `f_s` 接近滴水频率 `f_d` 的范围内：

| 频率关系 | 表观运动 |
| --- | --- |
| `f_s > f_d`，略高 | 图样缓慢向上，呈现“倒流” |
| `f_s = f_d` | 每次采到相同相位，图样悬停 |
| `f_s < f_d`，略低 | 图样缓慢向下 |

演示将真实下落与采样画面并列，提供倒流、悬停、慢落预设以及频率调节和逐次采样。物理模型采用等时间间隔释放水滴和重力下落；图像按数学采样时刻计算，并保持到下一采样时刻。它不改变显示器的物理刷新率，也不依靠整屏快速明暗闪烁制造效果。浏览器实际帧率可能影响显示流畅度，但不改变设定的采样频率关系。

这是解释时间采样与运动混叠的教学模型，并非对水滴破裂、流体动力学、照明曝光或人类视觉系统的精确模拟。表观倒流不表示水滴克服重力，也不表示同一颗水滴真实向上运动。上述频率比较针对接近基频的情况，不应推广到所有倍频或远离基频的采样条件。

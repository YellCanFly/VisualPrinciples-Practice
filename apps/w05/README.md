# W05 · 运动知觉与时间采样

本周是可继续增加案例的独立应用。第一部分为 **运动的快慢与节奏**，默认入口为 `w05/#motion-rhythm`；第二部分为 **水滴倒流**，保留入口 `w05/#water-strobe`。源码和依赖均保存在总工程内。

## 运行

在 `VisualPrinciples-Practice` 根目录运行 `npm run dev`，从课程首页进入 W05。已有根工程及旧周依赖时，只需在本目录首次执行 `npm install --no-audit --no-fund` 安装新周依赖。

只开发本周时，在本目录运行：

```powershell
npm run dev -- --port 5215 --base /w05/
```

随后打开 `http://127.0.0.1:5215/w05/#motion-rhythm`。独立运行只提供 W05，页面“课程首页”链接需通过总工程服务使用。

本周的最小检查可独立执行 `npm run typecheck`、`npm test`、`npm run build`。`typecheck` 在这个原生 JavaScript 应用中执行语法检查；没有 TypeScript 编译步骤。根工程仍按注册表完成统一构建与发布。

## 案例 01 · 运动的快慢与节奏

将课程 PPT“运动的快慢与节奏”章节转为可调参数的交互演示。曲线图、时间游标与物体位置使用同一进度；可暂停观察或重新播放，在相同位移下比较不同的时间分配。

| 内容 | 观察与操作 |
| --- | --- |
| 基础缓动 | 比较 Linear 与 Cubic 家族的 In、Out、InOut：匀速、加速、减速、慢起慢停。 |
| 幂次与常见曲线 | 比较 Quad、Cubic、Quart、Quint 的缓动强度，以及 Sine、Expo、Circ 的起停特征。 |
| Cubic Bézier | 调整两个控制点，观察曲线和运动如何变化，并与 CSS `ease` 预设比较。 |
| Back、Elastic、Bounce | 区分单次过冲、反复穿过目标的衰减振荡，以及触碰边界后的逐次回弹。 |
| Spring | 改变阻尼与初速度，比较欠阻尼、临界阻尼与过阻尼响应。 |
| Steps | 调整分段数与跳变位置，观察保持与瞬时跳转。 |
| 时长、延迟与错峰 | 分别改变一次运动持续多久、什么时候开始，以及多个元素相隔多久出发。 |
| 课堂练习 | 先观察运动，再判断对应的曲线。 |

曲线纵轴表示**运动进度**，不是速度。对于本例的直线运动，位置为 `起点 + 位移 × 进度`；相同距离与时长下，曲线斜率对应运动快慢。超出 100% 表示越过目标，下降段表示回移。改变总时长也会改变实际速度，不能只用归一化曲线的形状比较不同持续时间下的快慢。

基础 In／Out／InOut 明确采用 Cubic 幂函数，不等同于 CSS 同名 Bézier 关键词。Bézier 的横轴是输入时间：先由横坐标求曲线参数，再求纵坐标；不能直接把参数当作时间。控制点的 x 限于 `[0, 1]`，y 可以超出该范围以形成过冲。Steps 的跳变处没有有限的连续速度，不应按平滑曲线的斜率解释。

Spring 使用以秒计的质量—弹簧—阻尼模型，包含初速度。展示时长用于限定观察窗口，不把结果重新归一化，也不在窗口末尾强制吸附到目标。阻尼、质量、刚度和初速度共同决定响应；它与固定时长的 Elastic 曲线是不同模型。本例用于比较时间规律，不声称复刻某个品牌的实际动效参数。

## 案例 02 · 水滴倒流

参考视频：[《水滴为什么会倒流？这是频闪光源导致的》· 李论科学](https://www.bilibili.com/video/BV19W4y1E7qS)。

水滴周期性释放，每一滴都在重力作用下下落。频闪光源只让观察者看到离散时刻的水滴图样；相邻采样中看似同一颗的水滴，可能实际来自不同的水滴。

在光源频率 `f_s` 接近滴水频率 `f_d` 的范围内：

| 频率关系 | 表观运动 |
| --- | --- |
| `f_s > f_d`，略高 | 图样缓慢向上，呈现“倒流” |
| `f_s = f_d` | 每次采到相同相位，图样悬停 |
| `f_s < f_d`，略低 | 图样缓慢向下 |

演示将真实下落与采样画面并列，提供倒流、悬停、慢落预设以及频率调节和逐次采样。物理模型采用等时间间隔释放水滴和重力下落；图像按数学采样时刻计算，并保持到下一采样时刻。它不改变显示器的物理刷新率，也不依靠整屏快速明暗闪烁制造效果。浏览器实际帧率可能影响显示流畅度，但不改变设定的采样频率关系。

这是解释时间采样与运动混叠的教学模型，并非对水滴破裂、流体动力学、照明曝光或人类视觉系统的精确模拟。表观倒流不表示水滴克服重力，也不表示同一颗水滴真实向上运动。上述频率比较针对接近基频的情况，不应推广到所有倍频或远离基频的采样条件。

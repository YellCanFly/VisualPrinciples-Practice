# 反透视生成：实现与操作约定

更新日期：2026-10-22。此模块依据用户所附“目标立体效果 → 平面变形画 → 指定视点还原”示意实现。当前新模块取代“机位与焦距”界面。

## 生成的图像

输出是水平画面平面上的反透视变形图。从生成时指定的眼位看，平面画的透视投影与目标模型一致。主界面的三个视图分别用于检查还原效果、查看实际平面图案、理解眼位与虚拟模型的空间关系。

## 坐标和投影

使用右手系、Y 向上。实际画面平面为 `y=0`。内置或导入模型以最大包围尺寸归一到 2，居中后放在 `T=(0,1.2,0)` 附近。模型旋转围绕自身竖直轴。

眼位围绕 T 设置，由方向角 a、俯角 e、距离 d 得到：

```text
C = T + (d cos(e) sin(a), d sin(e), d cos(e) cos(a))
```

对模型世界坐标点 P，沿眼位 C 穿过 P 的射线继续延长，与画面平面相交：

```text
t = Cy / (Cy - Py)
Q = C + t(P - C)
Qy = 0
```

C、P、Q 共线，因此在同一理想透视相机中，P 与 Q 的 NDC 投影相同。参数范围保证眼位高于模型，交点保持有限；不合法输入应保留最近的有效结果。

## 颜色、可见面与透明度

目标模型首先从指定眼位渲染到透明纹理，得到该视点下的可见面、遮挡和明暗。实际画面平面通过投影纹理映射，按其世界点对应的眼位相机 UV 取色。指定视点效果仅绘制变形平面；源模型仅用于生成纹理及空间解释。

这种方式保留源视点的可见面关系。旋转空间观察相机只改变解释视图，不能改写指定眼位。

## 空间视图的重合检查

“从指定视点看”把空间相机的位置、朝向及视野同步到生成相机，观察目标设为 T；视口非正方形时只扩展取景范围，不改变眼位。开关“显示虚像”可以直接比较原模型轮廓与平面画。指定眼位模式会随参数、模型和视口更新；拖动、平移或缩放立即转为独立观察。“空间总览”恢复包含眼位与画面的侧视取景。

手动匹配观察方向不等于到达指定眼位，平面图的还原依赖观察者的完整位置。指定眼位下隐藏眼位标记与射线等辅助物，避免金色标记前方的锥体挡住相机；自由观察距离眼位标记小于等于 0.75 世界单位时也隐藏标记。虚像边线不写入深度缓冲，避免透明辅助线遮挡平面画。

## 导出

透明 PNG 采用画面平面的俯视正交取景。按所有投影顶点的 X/Z 范围与少量透明边距确定长宽；导出选项控制最长边像素，另一边按物理范围比例求值。

导出图只包含平面画。网格、眼位标记、虚拟模型、射线和 UI 标签不进入 PNG。背景 alpha 为 0，可见图案保留 RGBA；图像方向与平面预览一致。

打印时保持原图长宽比，随后按图像实际缩放比例安排观察位置。场景世界单位可整体等比例缩放，投影关系随之保持。

## 模型与 FBX

参考模型使用真实 Stanford Bunny、Utah Teapot、Suzanne 数据，来源单独列在 `ASSET_CREDITS.md`。运行时从本地构建资源加载。

FBX 按静态网格导入，归一尺寸并使用统一颜色；错误文件、空模型、非有限几何及超出限制的文件应被拒绝，保留上一模型。文件几何仅留在当前浏览器会话中；刷新后重新选择源文件。

## 验证原则

- 数学验证 P 与 Q 在同一相机中的投影一致，覆盖参数范围和极限视点。
- 实际浏览器操作视点滑块、模型选择和 FBX 导入，检查图像与空间关系变化。
- 对下载 PNG 解码检查非空图案、透明像素、最长边尺寸和实际平面长宽比。
- 使用根路径、仓库子路径与阻断外网场景检查资源自足。
- 人工目检变形图、指定视点还原图及空间图。软件渲染测试与真实打印/课堂投影的观察记录分别说明。
- 高分屏回归必须覆盖 DPR1/1.25/1.5/2，连续编辑、Orbit 后编辑与 resize 后编辑；将实际还原图与独立直接模型渲染逐像素比较，不能仅断言画面非空。

离屏源纹理使用物理像素尺寸，绑定渲染目标后由目标本身应用 viewport/scissor；不要再次调用带屏幕像素比缩放的 viewport 设置。生成源纹理后须恢复此前渲染目标及清屏状态。
